# パララックス背景 Leonardo AI プロンプト集

## 共通設定
- **モデル**: Leonardo Phoenix または SDXL


- **サイズ**: 1536 x 512（横長、3:1）
- **生成後の処理**: 各画像を横に2枚タイル結合（シームレス確認用）
- **書き出し**: PNG（透過あり）
- **ファイル命名**: `parallax_{theme}_{layer}.png`

## 共通サフィックス（全プロンプトの末尾に付ける）

```
seamless horizontal tileable pattern, 2D side-scrolling game art, cute kids game style, flat colors, no outlines, transparent background, no text, no characters, no UI elements
```

## 生成のコツ

1. **シームレス確認**: 生成した画像を横に2枚並べて継ぎ目をチェック。うまくいかない場合は Leonardo の「Tile」オプションを有効にする
2. **透過**: Leonardo で透過背景が出ない場合、白背景で生成 → Photoshop/Figma で白を透過に変換
3. **色の統一**: 同じテーマの4レイヤーは同じカラーパレットを維持。遠景ほど薄く、近景ほど濃く
4. **高さの使い方**:
   - 遠景: 画像の上半分に集中（山・天井・塔）
   - 中景: 画像の中央付近（木・柱）
   - 近景: 画像の下半分に集中（茂み・岩）
   - 地面: 画像の最下部のみ（薄い帯状）
5. **怖すぎない**: 魔王の城・闇テーマでも「cute kids game style」を必ず入れる。骸骨はかわいいカートゥーン調で
